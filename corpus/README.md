# lore — domain corpus

Reference corpus of the **lore** shokunin lane: the craft master's notebook
for fictional-world records — entities, relations, timeline — with
consistency verification and sourced inspiration.

Purposes: (1) reference guide — every claim cited to an in-world source or
flagged `invented`; (2) discovery corpus for new world material; (3)
inspiration source — real-world references enter through a reference ledger
with attribution/rights/training-permission kept distinct.

Provenance: seeded at mint 2026-10-12 (world-bible schema + consistency
checklist). Round history will accumulate on craft/* branches of this repo;
ledger in .shokunin/MANIFEST.json there.

Upstream: https://github.com/VeigaPunk/prymeagnt-lore — local execution
references it with: git fetch lore main
